# Tick data format

Recorded and simulated market data share one CSV format. It is read by the `ReplayProvider` (`DATA_TIER=replay`) and written by the sample generator.

## Columns

| Column     | Type              | Notes                                                                         |
| ---------- | ----------------- | ----------------------------------------------------------------------------- |
| `ts`       | ISO 8601 UTC      | Exchange timestamp, millisecond precision (`2027-03-15T08:00:00.000Z`)        |
| `source`   | enum              | `sim`, `replay`, `pyth`, `tradegate`, `xetra-delayed`, `eurex`                |
| `venue`    | enum              | MIC, or an internal code: `FX`, `LSX`, `USON` (US overnight), `OTCM`          |
| `symbol`   | text              | Venue symbol; may contain spaces (`NOVO B`), never commas or quotes           |
| `kind`     | enum              | `quote`, `trade`, `auction` (opening print), `indicative`, `close` (official) |
| `currency` | enum              | `EUR`, `USD`, `GBP`, `GBX` (pence), `DKK`                                     |
| `bid`      | decimal, optional | Quotes                                                                        |
| `ask`      | decimal, optional | Quotes                                                                        |
| `last`     | decimal, optional | Trades, auctions, indicatives, closes                                         |
| `size`     | decimal, optional | Shares                                                                        |

Rules:

- The first line is the header, exactly `ts,source,venue,symbol,kind,currency,bid,ask,last,size`.
- Rows are sorted by `ts`. Empty optional fields stay empty.
- Files may be gzip-compressed (`.csv.gz`).
- FX rows use the pair as the symbol (`EURUSD`, `EURGBP`, `EURDKK`). Their currency is the quote currency.
- Parquet input is planned but not implemented. Convert Parquet to this CSV format first.

## Committed sample (`data/sample/`)

`sim-2027-03-15_2027-03-31.csv.gz` holds about 214k ticks, generated by the simulated world with seed 42. `manifest.json` records:

- the seed;
- the markets: ASML, SAP, NOVO, SHEL, TTE;
- the thinning rule: the first quote/trade per instrument per 60 s, all other kinds kept;
- every injected fault.

It covers:

- the US-only DST weeks (US switched on 14 Mar, the EU switches on 28 Mar 2027);
- Good Friday and Easter Monday (26 and 29 Mar 2027);
- the simulated ex-dividend days of ASML (local 23 Mar, ADR 24 Mar), TTE (24/25 Mar) and NOVO (30 Mar);
- DKK and GBX primary lines, and US pre-market, after-hours and overnight quotes.

Regenerate it with `pnpm --filter @euroedge/data-adapters sample`. The output is deterministic, so the file only changes when the simulator or the configuration changes.

The prices are **synthetic**. They must never be shown as real prices (brief §4.1).
