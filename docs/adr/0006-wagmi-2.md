# ADR-0006 — wagmi 2 + viem 2 + RainbowKit 2.2

- **Status:** Accepted (founder, 2026-10-27)

## Context

On 2026-10-27, wagmi `latest` is 3.7.9. However, `@rainbow-me/rainbowkit@2.2.11` (latest) still peers `wagmi ^2.9.0`.

## Decision

- Pin **wagmi 2.19.x + viem 2.x + RainbowKit 2.2.11** together.
- All wallet code lives in `apps/web/src/wallet/*`: config, connectors, the SIWE adapter, and the wagmi `mock` connector for e2e.
- Revisit when RainbowKit supports wagmi 3. Alternatives (Reown AppKit, ConnectKit) need a new ADR.

## Consequences

- Some ageing of the wallet stack. The blast radius is one module.
