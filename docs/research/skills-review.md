# Agent-skills review (2026-10-27)

**Source.** The founder pointed to the "Skill Issue" directory (skill-issue.in, finance domain and related). Each candidate was fetched as data from GitHub and **read in full before any decision**. A skill becomes instructions for the coding agent, so unread or self-updating skills are not installed.

## Installed (`.claude/skills/`, pinned, MIT)

| Skill                                     | Why it fits                                                                                                                                                                             | Overrides (see `CLAUDE.md`)                                                  |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `web-interface-guidelines` (Vercel)       | Concrete, checkable rules for a11y, focus, forms, i18n (`Intl.*`, `translate="no"`), theming (`color-scheme`, `theme-color`), URL-reflected state and anti-patterns. Matches brief §11. | Pinned copy instead of a runtime fetch; sentence case instead of Title Case. |
| `make-interfaces-feel-better` (J. Krehel) | Motion restraint, no bounce, tabular numbers, concentric radii, hit areas, no `transition: all`. Matches the "Linear restraint" direction.                                              | No press-scale or staggered entrances in the terminal.                       |
| `accessibility` (A. Osmani)               | WCAG 2.2-specific: 2.4.11 focus not obscured, 2.5.7 dragging alternatives, 2.5.8 target size, 2.1.4 single-key shortcuts, 3.3.8 accessible authentication.                              | Repo-pinned axe/Lighthouse instead of global installs.                       |
